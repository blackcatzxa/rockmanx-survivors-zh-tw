# 洛克人 X 倖存者｜繁體中文漢化包

這是《Rockman X Survivors》的非官方繁體中文漢化包。遊戲本體請先到原作者的 Releases 下載。

- [下載漢化包](../../releases/latest)
- [下載遊戲本體｜原作者 GitHub Releases](https://github.com/gaho727/rockmanx-survivors/releases)

## 目前版本

對應遊戲 v1.6.0。此版使用 v1.5.2 的安裝工具搭配 v1.6.0 翻譯表，已在 v1.6.0 驗證可套用 1,376 處文字。

## 安裝方式

1. 關閉遊戲。
2. 在漢化包 Release 的 **Assets** 下載漢化 ZIP。
3. 把 ZIP 解壓縮到遊戲根目錄，讓 `Translate.bat` 與 `RockmanXSurvivors.exe` 位於同一層。
4. 執行 `Translate.bat`。重新開遊戲後，在 **Settings → Game → Language** 選擇「繁體中文」。

要還原時，關閉遊戲後執行 `Restore.bat`。請保留安裝時建立的 `_RXS_zhTW` 備份資料夾。
